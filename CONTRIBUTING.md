# Guia de contribuição

Obrigado pelo interesse em contribuir com este portfólio.

## Como contribuir

1. Sugira melhorias para o site.
2. Identifique erros ou problemas de apresentação.
3. Proponha melhorias na documentação.
4. Mantenha o código simples e organizado.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

Este projeto tem como objetivo apresentar meu perfil profissional, meus estudos e minha evolução na área de tecnologia e Ciência de Dados.
