# Israel Vitor — Portfólio

Site de portfólio responsivo, bilíngue (português/inglês), feito com HTML, CSS e JavaScript puro.

## Visualizar
Abra o arquivo `index.html` no navegador.

## Publicar com GitHub Pages
1. Crie um repositório público chamado `vitor1914.github.io` no GitHub.
2. Envie `index.html` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)` e salve.
6. Aguarde a publicação em `https://vitor1914.github.io/`.

## Personalizar
Confira os links dos repositórios e altere os textos diretamente no `index.html` se necessário. O botão EN/PT troca o idioma sem bibliotecas externas.
